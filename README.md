# 干瞪眼 · 星际版 — Web 版

按照 `设计稿/` 目录下的 13 张界面设计稿实现的**干瞪眼**纸牌游戏 Web 版。

- ✅ **联网对战**：竞技场 / 大师场走真实匹配房，手机浏览器访问局域网地址即可加入
- ✅ **和电脑对战**：练习场秒开一桌 3 个 AI；匹配等待超时自动补 AI
- ✅ **移动端适配**：竖屏 / 横屏 / 桌面自适应，触控操作；支持 **PWA 安装**到手机桌面（全屏运行、静态资源离线缓存）
- ✅ **动效**：出牌飞入牌堆、开局逐张发牌、摸牌弹入、炸弹/火箭全屏特效
- ✅ 按设计稿还原：启动封面、登录、加载、首页、等待连接、对战、赢/输结算、设置、英雄榜、接任务、普通确认窗、菜单弹出、个人中心（更换头像 / 游戏记录）

## 快速开始

```bash
npm install
npm start          # 默认 http://localhost:3000
```

打开浏览器访问 <http://localhost:3000>：

- 登录页输入用户名/密码自动注册，**留空直接点 Play 则以游客身份进入**；
- 练习场 = 人机对战（免费）；竞技场 / 大师场 = 联网匹配（每场入场费 5 / 20 能量）。

**手机联机**：手机与电脑连同一 Wi-Fi，浏览器访问 `http://<电脑IP>:3000` 即可匹配同一场对局。断网重进会自动回到牌局（由电脑代打直到你回来）。

## 玩法规则（干瞪眼）

| 项目 | 规则 |
| --- | --- |
| 牌 | 一副 54 张，点数 3 < 4 < … < K < A < 2 < 小王 < 大王 |
| 发牌 | 每人 5 张，其余作牌堆，摸一张打一张 |
| 牌型 | 单张、对子、**炸弹**(三张相同)、**氢弹**(四张相同)、**火箭**(大小王) |
| 压牌 | 同张数比点数；炸弹/氢弹/火箭可越级压制任意非炸弹牌型 |
| 过牌 | 压不上（或不想压）摸一张牌跳过；一圈都不要则最后出牌者重新领出 |
| 胜负 | 先出完手牌者赢，结算后自动开下一局，庄家为上局赢家 |
| AI | 练习场=新手（偶尔乱出）、竞技场=普通（稳最小牌）、大师场=高手（不拆牌型、防送单张、择机用炸弹） |

**计分**：每个输家支付 `(剩余牌数 + 炸弹×2 + 氢弹×4 + 火箭×8) × 场地赔率`，赢家另收全场底注。练习场免费只记战绩。

## 功能清单

- 注册/登录/游客登录、切换账号（服务端会话 + JSON 存档）
- 三种场地：练习场（人机）/ 竞技场 / 大师场（联网匹配 + 换桌 + 等待倒计时）
- 完整对局：选牌、提示（可循环切换候选牌型）、重选、不出、30 秒倒计时超时自动代打
- **托管**（菜单开启，AI 代打）、**记牌器**（各点数余牌统计）
- **PWA**：`public/manifest.webmanifest` + `public/sw.js`，手机浏览器「添加到主屏幕」后全屏运行；断网时静态页面仍可加载（对局自然需要联网）
- 结算面板：剩余牌数 / 炸弹 / 氢弹 / 火箭 与能量收支明细
- 每日任务（完成任意 3 场、打出 3 炸弹等，奖励能量）、英雄榜（战神/连胜/能量/奖杯/任务 五个榜）
- 个人中心：12 款机器人头像更换 + 随机生成；三场地战绩表（场次/胜率/能量/积分）
- 设置：音乐 / 声效音量（WebAudio 合成音效，无外部音频文件）
- 炸弹/氢弹/火箭全屏特效、要不起气泡、发牌动画、星空背景

## 项目结构

```
├── server.js              # Express + Socket.IO 入口（登录、匹配、对局事件）
├── lib/
│   ├── game.js            # 规则引擎（服务端与浏览器共用同一份代码）
│   ├── rooms.js           # 房间/匹配/回合流程/AI 代打/结算
│   └── store.js           # JSON 存档（用户、会话、任务、英雄榜）
├── public/
│   ├── index.html         # 全部界面（单页）
│   ├── css/style.css      # 星际科幻风 UI + 移动端适配
│   └── js/
│       ├── main.js        # 路由、socket、对战交互、各弹窗
│       ├── ui.js          # 牌面渲染、头像、弹窗、Toast、星空
│       └── sound.js       # WebAudio 音效/背景音乐
├── test/engine.test.js    # 规则引擎自测（npm test）
├── data/db.json           # 运行时自动生成的存档
└── 设计稿/                # 原设计稿与 logo
```
